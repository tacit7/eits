Current session workflow status and suggested next command

Usage: eits workflow [OPTIONS] <COMMAND>

Commands:
  status  Concise current session workflow status
  finish  Log commits, close a task, notify its parent, and check the inbox
  help    Print this message or the help of the given subcommand(s)

Options:
      --pretty  Pretty-print JSON output (default: compact; or EITS_PRETTY=1)
  -q, --quiet   Print only the created/affected ID on success (mutations)
  -h, --help    Print help
